# Kiri Tarot Studio — GitHub Pages

No installation or build is needed. The booking button and QR code both open your Google Form.

## Publish using GitHub in your browser
1. Sign in at https://github.com and create a new PUBLIC repository named kiri-tarot-studio. Enable Add README.
2. Download and extract this ZIP on your computer.
3. In the repository, select Add file > Upload files.
4. Drag the CONTENTS of the extracted folder into GitHub: index.html, style.css, app.js, assets folder and this README. Do not upload the ZIP or put everything inside an extra folder. Include .nojekyll if it is visible; this plain HTML site also works without it.
5. Click Commit changes.
6. Open Settings > Pages.
7. Under Source, choose Deploy from a branch. Choose main and /(root), then Save.
8. Wait for deployment to complete. The Pages settings will show the live website link.

The project URL has this format: https://YOUR-USERNAME.github.io/kiri-tarot-studio/

## Check after publishing
- Open the booking form button and check it accepts responses.
- Scan the booking QR code with your phone: it goes directly to your Google Form.
- Open a client original message and expand all nine reviews.
- Check the page on your phone.

## Files
index.html: page content and package prices.
style.css: black-and-gold design and responsive layouts.
app.js: original-review viewer and review expansion; no backend.
assets/: logo, anonymized client review screenshots and booking QR code.

English review excerpts are translations or shortened excerpts, not star ratings. The relationship reading price was interpreted as 50,000 MMK from the partially cut-off package screenshot; please confirm before launch.
